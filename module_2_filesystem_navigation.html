1. Linux Directory Structure

Linux has one main filesystem tree. Everything starts from the root directory: /. Think of it like a city map where every road begins at the main gate.

root: start of everything
├── user homes
│   └── your room
├── configuration
├── logs and changing data
├── temporary files
├── basic commands
└── applications and tools

📍 / — Root directory

The root directory is the top of the Linux filesystem. Every absolute path starts from here.

Example: /home/student/linux-lab
🏠

/home

User files live here. For example, a user named student usually has files under /home/student.

⚙️

/etc

System and service configuration files live here. This is the Linux control room. Do not randomly edit files here as root.

📦

/var

Variable data lives here, such as logs, caches, queues, and files that change often.

🧹

/tmp

Temporary files live here. Many systems clean this automatically, so do not store important work here.

2. Absolute vs Relative Path

A path tells Linux the location of a file or directory. The main difference is whether the path starts from / or from your current location.

🧱 Absolute path

Starts from the root directory /. It works from anywhere.

/home/student/linux-lab/file1.txt
✅
Memory trick:
Absolute path gives the full address from the city gate.

🚶 Relative path

Starts from where you are currently standing in the filesystem.

linux-lab/file1.txt
⚠️
Careful:
Relative paths can change meaning depending on your current directory.

3. Command Cards

These are the core commands for this module. Learn them like tools in a small toolbox.

Lists visible files and directories.

ls

Lists all files, including hidden files, with details.

ls -la

Moves you from one directory to another.

Create directory

Creates a new folder.

Create empty file

Creates a blank file or updates file timestamp.

touch file1.txt
🤦
Classic beginner trap:
cd etc and cd /etc are different. cd /etc goes to the real system configuration directory. cd etc tries to enter an etc directory inside your current location.

4. Listing Files and Hidden Files

Linux hides files whose names start with a dot. They are not special magic files; the dot simply tells normal ls to hide them.

Normal listing

ls shows regular visible files.

student@linux:~$ ls
Documents Downloads linux-lab

Detailed listing

ls -la shows permissions, owner, size, time, visible files, and hidden files.

student@linux:~$ ls -la
drwxr-xr-x 5 student student 4096 Aug 2 .
drwxr-xr-x 3 root root 4096 Aug 2 ..
-rw-r--r-- 1 student student 220 Aug 2 .bash_logout
-rw-r--r-- 1 student student 3771 Aug 2 .bashrc
drwxr-xr-x 2 student student 4096 Aug 2 linux-lab
👀
Hidden file rule: A file named .bashrc is hidden because it starts with a dot. To see it, use ls -a or ls -la.

5. Guided Lab: First Navigation Mission

Run these commands on your Linux VM or terminal. Use the expected output to check whether you are on the right path.

Mission 1: Check your current location

student@linux:~$ pwd

Expected output:

/home/student

Your username may be different. For example, /home/jp is also normal if your username is jp.

Mission 2: List files with details

student@linux:~$ ls -la

Expected output pattern:

drwxr-xr-x ... .
drwxr-xr-x ... ..
-rw-r--r-- ... .bashrc
drwxr-xr-x ... Documents

Exact files can differ. The important point is that hidden files beginning with . should appear.

Mission 3: Move to /etc

student@linux:~$ cd /etc
student@linux:/etc$ pwd

Expected output:

/etc

/etc is an absolute path, so it works from anywhere.

Mission 4: Return home

student@linux:/etc$ cd ~
student@linux:~$ pwd

Expected output:

/home/student

~ means your home directory.

Mission 5: Create a lab directory

student@linux:~$ mkdir linux-lab
student@linux:~$ ls

Expected output should include:

linux-lab

If it says File exists, the directory was already created earlier. Not a disaster; Linux is just being very literal.

Mission 6: Create a blank file

student@linux:~$ cd linux-lab
student@linux:~/linux-lab$ touch file1.txt
student@linux:~/linux-lab$ ls -la

Expected output should include:

-rw-r--r-- 1 student student 0 Aug 2 file1.txt

The size is 0 because touch created an empty file.
